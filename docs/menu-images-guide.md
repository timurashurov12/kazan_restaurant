# Фотографии для меню ресторана Kazan

Источники: **Unsplash** (бесплатно, без атрибуции) и **Pexels** (бесплатно, без атрибуции).

## Как использовать

1. Перейдите по ссылке в разделе
2. Выберите фото, которое нравится (рекомендуемый стиль: вид сверху или 45°, тёмный фон, тёплое освещение)
3. Скачайте в высоком разрешении
4. Загрузите через админку: `/admin/menu-items/:id/edit` → поле «Изображение»

## Рекомендации по стилю

Для единообразия меню рекомендуем придерживаться одного стиля:

- **Ракурс:** вид сверху (flat lay) или 45 градусов
- **Фон:** тёмный (дерево, сланец, чёрный мрамор) — соответствует стилю сайта (`--color-app-bg: #0c0a09`)
- **Освещение:** тёплое, мягкое, боковое
- **Подача:** минималистичная, без лишних декораций
- **Формат:** квадратный или 4:3 для единообразия
- **Разрешение:** минимум 800×800 px
